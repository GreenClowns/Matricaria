# Как участвовать

Спасибо за интерес к Matricaria!

1. Перед крупными изменениями откройте Issue и опишите идею.
2. Важные решения записываются в [docs/decisions.md](docs/decisions.md).
3. Код ядра на Python: стиль PEP 8, к новой логике нужны тесты в `tests/`.
4. Godot отвечает только за отображение, игровая логика живёт в ядре ([docs/03-architecture.md](docs/03-architecture.md)).
5. Можно использовать только открытые зависимости и ресурсы с совместимыми лицензиями. Авторов добавляйте в [CREDITS.md](CREDITS.md).

Отправляя изменения, вы соглашаетесь распространять их под GPL-3.0.
