# 13. Риски

Список того, что может пойти не так, и что мы с этим делаем.
Пересматривается после каждой версии.

## ИИ

| Риск | Вероятность | Что делаем |
|---|---|---|
| **Противоречия в тексте** (NPC говорит, что мёртвый жив) | Средняя | Валидатор, знания NPC, кнопка «Это неправда», тесты ([07](07-validator.md)) |
| **Валидатор сам ошибается** (он тоже ИИ) | Средняя | Критичное проверяет код: предметы, деньги, смерть, перемещения |
| **Сломанный JSON** | Низкая у API, выше у маленьких моделей | JSON-схема, грамматика llama.cpp, повтор запроса |
| **Персонаж «плывёт»** в долгой игре | Средняя | Карточка в каждом запросе, сводки, примеры реплик |
| **Медленно:** 2–3 запроса на реплику | Средняя | Проверки параллельно; для простых реплик пропускать |
| **Цена API** в долгих сессиях | Средняя | Дешёвая модель для проверок, сильная для диалогов, локальный режим |
| **Ограничения содержания** у API | Зависит от провайдера | Локальная модель как запасной вариант |
| **Провайдер отключит модель** | Со временем — высокая | Единый интерфейс, модель меняется в настройках |

## Графика

| Риск | Вероятность | Что делаем |
|---|---|---|
| Портреты одного персонажа выглядят по-разному | Высокая | Фиксированный seed, подробное описание, позже IP-Adapter |
| Генерация медленная на слабом ПК | Высокая | Наборы эмоций генерируются заранее, кэш, профиль «Лёгкий», API |
| Лицензии весов моделей (OpenRAIL) | Средняя | Менеджер моделей показывает лицензию, записываем в CREDITS |

## Проект

| Риск | Вероятность | Что делаем |
|---|---|---|
| **Проект слишком большой** и не доходит до игры | Высокая | Маленькие версии, у каждой проверяемый результат |
| Автор не программист | — | Команды готовыми блоками, понятные объяснения, `CLAUDE.md` |
| Чаты не помнят друг друга | Высокая | Вся память в репозитории: документы, решения, CHANGELOG |
| Конфликты при работе нескольких чатов | Средняя | 1–2 чата одновременно, ветки и Pull Request ([14](14-workflow.md)) |
| Своя графика в стиле «аниме-пиксель» (D32): готового открытого набора нет, рисовать долго | — | Сборка персонажей из слоёв, как в макете; генерация в 0.9; помощь художников; авторы — в `CREDITS.md` и на экране «Авторы» |
