# 08. Симуляция мира (черновик)

Мир живёт по **правилам, без ИИ**: это быстро, бесплатно и без выдумок.
ИИ нужен только для разговоров и пересказа событий.

## Время

- 1 тик = 1 игровая минута рядом с игроком.
- Скорости: пауза, ×1, ×4.
- Пропуск: до утра, +1 день, неделя, месяц, год или своё значение.
- Мир может жить, пока программа закрыта (настройка; по умолчанию выключено).

## Уровни детализации

| Где | Шаг |
|---|---|
| Рядом с игроком | 1 минута |
| Тот же город | 1 час |
| Далёкие регионы | 1 день |
| Пропуск больше месяца | 1 неделя, только итоги |

## NPC

- **Распорядок:** работа, еда, сон, отдых. Зависит от роли и дня недели.
- **Потребности:** еда, деньги, общение, безопасность, отдых (0–100, падают со временем).
- **Цели:** долгие задачи из шагов (накопить на лавку → купить → открыть).
- **Связи:** NPC общаются друг с другом, и их отношения меняются.

## События

Шаблон события:
```yaml
id: drought
условия: сезон = лето, осадки за месяц < 10
вероятность: 0.05 в день
эффекты: урожай −50%, цена зерна ×1.8
новость: "Засуха: зерно дорожает"
```
Шаблоны хранятся в файлах, поэтому их можно добавлять без программирования.

## Слухи

- Событие видят свидетели: они получают факт со статусом `truth`.
- Каждый день свидетели могут рассказать его знакомым, и те получают его как `rumor`.
- С каждым пересказом есть шанс искажения (число, имя, место).
- Торговцы и трактирщики разносят слухи быстрее.

## Детерминированность

Вся случайность берётся из seed мира, поэтому один и тот же seed и одни и те же действия дают один и тот же результат. Это нужно для тестов и откатов.
