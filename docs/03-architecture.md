# 03. Архитектура

## Слои

```
┌──────────────────────────────────────────────┐
│ 4. ИНТЕРФЕЙС — Godot 4                       │  рисует и передаёт нажатия
└───────────────▲──────────────────────────────┘
                │ WebSocket (localhost), JSON
┌───────────────┴──────────────────────────────┐
│ 3. ИИ-РАССКАЗЧИК — Python → llama.cpp / API  │  пишет текст, ПРЕДЛАГАЕТ действия
├──────────────────────────────────────────────┤
│ 2. ВАЛИДАТОР — Python                        │  проверяет предложения ИИ
├──────────────────────────────────────────────┤
│ 1. ЯДРО МИРА — Python + SQLite               │  единственный источник правды
│    факты · журнал событий · симуляция        │
└──────────────────────────────────────────────┘
        │                         │
  llama-server              stable-diffusion.cpp
  (текст)                   (портреты, фоны)
```

## Правила

1. **Godot ничего не решает.** Он показывает состояние и отправляет намерения игрока («идти», «сказать», «пропустить день»).
2. **Только ядро меняет базу.** ИИ и интерфейс работают через ядро.
3. **ИИ — это сменный модуль.** Локальная модель и API используют один и тот же интерфейс (OpenAI-совместимый).
4. **Ядро работает без графики:** его можно запустить из консоли и покрыть тестами.

## Запуск

1. Пользователь открывает Matricaria (исполняемый файл Godot).
2. Godot запускает Python-ядро как дочерний процесс.
3. Ядро при необходимости запускает `llama-server` и `stable-diffusion.cpp`.
4. Godot подключается к ядру по WebSocket.
5. При закрытии Godot останавливает ядро, а ядро останавливает модели.

## Структура репозитория

```
core/matricaria/
  world/       — модели данных, работа с базой, снимки
  sim/         — время, распорядки, события, слухи
  ai/          — провайдеры (llama.cpp, API), сборка запроса
  validator/   — проверка действий и фактов
  memory/      — сводки, лорбук, знания NPC
  server/      — WebSocket-сервер для Godot
game/          — проект Godot
assets/        — графика, логотип
tools/         — установка моделей, сборка
tests/         — тесты ядра
```
