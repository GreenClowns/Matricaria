# 10. Дорожная карта

Сначала строится основа, графика добавляется потом.
У каждого этапа есть результат, который автор проверяет у себя на компьютере.

| Этап | Что делаем | Как проверить |
|---|---|---|
| **0. Документы** ← мы здесь | Видение, архитектура, схема базы, протокол | Автор прочитал и согласовал |
| **1. Ядро** | База SQLite, факты, журнал событий, снимки и откат | Создать мир командой, откатить |
| **2. Симуляция** | Время, распорядки, потребности, события, слухи | Пропустить месяц и прочитать журнал |
| **3. ИИ-шлюз** | llama.cpp и API, сборка запроса, JSON-ответы | Поговорить с NPC в консоли |
| **4. Валидатор** | Действия, проверка фактов, очередь утверждения | Тест на 100 реплик |
| **5. Память** | Сводки, лорбук, знания NPC | Длинная сессия без потерь |
| **6. Godot: мир** | Карта, LPC-персонаж, ходьба | Пройтись по деревне |
| **7. Godot: диалог** | Сцена, 5 персонажей, задний план, чат | Поговорить в окне игры |
| **8. Генераторы** | stable-diffusion.cpp, пиксельная обработка, менеджер моделей | Сгенерировать портрет |
| **9. Редакторы и генерация мира** | Редактор персонажа, фэнтези и город | Создать героя и мир без кода |
| **10. Упаковка** | AppImage / Flatpak, затем Windows | Установить на чистую систему |
