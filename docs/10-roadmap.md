# 10. Дорожная карта

Сначала строится надёжная основа, графика добавляется потом.
У каждой версии есть результат, который автор проверяет у себя на компьютере.

**Сейчас: идёт 0.4 «Симуляция» (часть 1 готова).** Версии 0.3 и 0.3.5 завершены 28.10.2026, 0.1 — 26.10.2026.

## Обзор

| Версия | Название | Результат для автора | Статус |
|---|---|---|---|
| **0.1** | Планирование | Согласованные документы, макет, правила работы | 🟢 готово |
| **0.2** | Эксперимент: надёжность ИИ | Отчёт с цифрами: насколько ИИ ошибается через API и локально | 🟢 готово |
| **0.3** | Ядро мира | Создать мир командой, записать события, откатиться | 🟢 |
| **0.3.5** | Окно мира | Увидеть мир в окне, походить героем, сделать снимок и откатиться кнопкой | 🟢 |
| **0.4** | Симуляция | Пропустить месяц и прочитать, что произошло | 🟡 |
| **0.5** | ИИ и валидатор | Поговорить с NPC в консоли, ИИ не ломает факты | ⚪ |
| **0.6** | Память | Длинная сессия без потери фактов, лорбук, сводки | ⚪ |
| **0.7** | Godot: мир | Пройтись по пиксельной деревне | ⚪ |
| **0.8** | Godot: диалог и бой | Сцена с 5 персонажами, разговор и бой в окне игры | ⚪ |
| **0.9** | Генераторы и редакторы | Создать героя без кода, сгенерировать портрет и мир | ⚪ |
| **1.0** | Первая играбельная версия | Установить программу и играть | ⚪ |

Статусы: 🟢 готово · 🟡 идёт · ⚪ не начато.
Номера версий после 0.2 могут сдвинуться по результатам эксперимента.
