# 10. Дорожная карта

Сначала строится надёжная основа, графика добавляется потом.
У каждой версии есть результат, который автор проверяет у себя на компьютере.

**Сейчас: версия 0.1 — планирование.**

## Обзор

| Версия | Название | Результат для автора | Статус |
|---|---|---|---|
| **0.1** | Планирование | Согласованные документы, макет, правила работы | 🟡 идёт |
| **0.2** | Эксперимент: надёжность ИИ | Отчёт с цифрами: насколько ИИ ошибается через API и локально | ⚪ |
| **0.3** | Ядро мира | Создать мир командой, записать события, откатиться | ⚪ |
| **0.4** | Симуляция | Пропустить месяц и прочитать, что произошло | ⚪ |
| **0.5** | ИИ и валидатор | Поговорить с NPC в консоли, ИИ не ломает факты | ⚪ |
| **0.6** | Память | Длинная сессия без потери фактов, лорбук, сводки | ⚪ |
| **0.7** | Godot: мир | Пройтись по пиксельной деревне | ⚪ |
| **0.8** | Godot: диалог | Сцена с 5 персонажами, разговор в окне игры | ⚪ |
| **0.9** | Генераторы и редакторы | Создать героя без кода, сгенерировать портрет и мир | ⚪ |
| **1.0** | Первая играбельная версия | Установить программу и играть | ⚪ |

Статусы: 🟢 готово · 🟡 идёт · ⚪ не начато.
Номера версий после 0.2 могут сдвинуться по результатам эксперимента.

## 0.2 — Эксперимент: надёжность ИИ ⚪

**Цель:** проверить на цифрах, что идея «ИИ описывает, ядро решает» работает. Подробности — в [12-ai-experiment.md](12-ai-experiment.md).

- [ ] Маленький тестовый мир: 3 NPC, ~20 фактов, предметы
- [ ] 100 тестовых реплик с ловушками
- [ ] Упрощённый валидатор (проверка действий кодом, сверка фактов)
- [ ] Прогон через API (сильная и дешёвая модель)
- [ ] Прогон локально через llama.cpp на компьютере автора
- [ ] Отчёт: ошибки, сломанный формат, скорость, цена

**Готово, когда:** есть отчёт, и по нему принято решение — архитектура остаётся или меняется.

## 0.3 — Ядро мира ⚪

**Цель:** база данных, в которой живёт правда о мире. См. [03](03-architecture.md), [04](04-database.md).

- [ ] Пакет `core/matricaria/world`: модели данных и SQLite
- [ ] Факты со статусами (`truth`, `belief`, `rumor`, `lie`) и знания NPC
- [ ] Характеристики, здоровье, предметы, деньги
- [ ] Несколько героев игрока (`controller`) и автор у каждого события (`actor_id`)
- [ ] Журнал событий (только дополняется)
- [ ] Снимки и откат
- [ ] Консольная команда: создать мир, показать состояние, откатиться
- [ ] Тесты

**Готово, когда:** автор создаёт мир командой в терминале, делает изменения и откатывается назад.

## 0.4 — Симуляция ⚪

**Цель:** мир живёт без игрока. См. [08](08-simulation.md).

- [ ] Игровое время, скорости, пропуск времени
- [ ] Распорядок и потребности NPC
- [ ] Цели NPC
- [ ] Шаблоны событий в файлах (засуха, свадьба, ярмарка…)
- [ ] Распространение слухов с искажениями
- [ ] Уровни детализации (рядом / город / далеко)

**Готово, когда:** после команды «пропустить месяц» журнал содержит правдоподобные события, а повторный запуск с тем же seed даёт тот же результат.

## 0.5 — ИИ и валидатор ⚪

**Цель:** разговор с NPC, который не ломает мир. См. [06](06-ai-formats.md), [07](07-validator.md).

- [ ] Провайдеры: встроенный llama.cpp, Ollama / LM Studio, OpenRouter, NanoGPT и «свой адрес»
- [ ] Разные модели для разных задач (диалоги / проверки / сводки)
- [ ] Сборка запроса из карточки, отношений, знаний, сцены
- [ ] JSON-схема и грамматика ответа
- [ ] Проверка действий кодом
- [ ] Проверки d20, бой и торговля (кубики бросает ядро)
- [ ] Извлечение и сверка фактов, очередь «На утверждение»
- [ ] Хроника после пропуска времени (строго по журналу)
- [ ] Консольный чат с NPC

**Готово, когда:** автор разговаривает с NPC в терминале, а тест из 0.2 показывает не больше 2% пропущенных противоречий.
