# 04. База данных (черновик)

Один мир хранится в одном файле SQLite: `saves/<мир>/world.db`.

## Таблицы

| Таблица | Что хранит | Ключевые поля |
|---|---|---|
| `world` | Параметры мира | id, название, сеттинг, seed, текущее время |
| `location` | Локации и здания | id, название, тип, координаты, родительская локация |
| `character` | Герои и NPC | id, имя, роль, характер (JSON), спрайт, портреты, controller (кто управляет: ИИ или игрок №…) |
| `stats` | Характеристики и состояние | character_id, сила, ловкость, выносливость, ум, обаяние, здоровье, состояния (ранен, оглушён…) |
| `need` | Потребности NPC | character_id, вид (еда, деньги, общение…), значение |
| `goal` | Цели NPC | character_id, описание, прогресс, статус |
| `schedule` | Распорядок | character_id, время, локация, занятие |
| `relation` | Отношения | from_id, to_id, симпатия, доверие, страх, знает_имя |
| `item` | Предметы | id, тип, владелец, локация, базовая цена, надето/в руках, урон (для оружия) |
| `market` | Цены в регионе | регион, тип товара, спрос, предложение, множитель цены |
| `faction` | Фракции | id, название, влияние |
| `fact` | Факты о мире | subject, predicate, object, статус, canon, since, source |
| `knowledge` | Кто какой факт знает | character_id, fact_id, верит (да/нет), откуда узнал |
| `event` | Журнал событий (**только дополняется**) | id, время, тип, actor_id (кто совершил), участники, данные (JSON), броски кубиков |
| `message` | Сообщения диалогов | id, сцена, автор, текст, время |
| `summary` | Сводки | уровень (блок / глава / хроника), текст, ссылки на события, закреплена |
| `lore_entry` | Лорбук | название, тип, ключи, условия, текст, приоритет, видимость |
| `pending` | Очередь на утверждение | вид, данные, источник |
| `snapshot` | Снимки для отката | id, время, ссылка на последнее событие, файл |
| `asset` | Картинки | id, владелец, вид (спрайт / портрет / фон), эмоция, seed, путь |

## Статусы факта

- `truth`: так есть на самом деле.
- `belief`: так думает NPC, хранится в `knowledge`.
- `rumor`: слух.
- `lie`: NPC сознательно говорит неправду.

## Пример

```json
{ "subject": "npc_17", "predicate": "spouse_name", "object": "Марта",
  "status": "truth", "canon": false, "since": "день 12", "source": "dialog_88" }
```

## Откат

Снимок — это копия базы на определённый момент. Откат = восстановить снимок, и всё, что было после, становится отдельной веткой.
