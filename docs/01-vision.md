# 01. Видение

## В одном предложении

Matricaria — пиксельная ролевая песочница, где мир живёт по своим правилам, а персонажи разговаривают с помощью ИИ, не забывая и не переписывая историю мира.

## Для кого

- Любители ролевых игр с ИИ-персонажами (как SillyTavern), которым нужен **целый мир**, а не просто чат.
- Те, кто хочет создавать своих персонажей и миры **без программирования**.
- Те, кто хочет играть **локально**, без подписок и облака.

## Чем отличается

| Обычный ИИ-чат | Matricaria |
|---|---|
| Только текст | Пиксельный мир, по которому можно ходить, и сцена с портретами |
| ИИ забывает и путает факты | Факты хранятся в базе, ИИ их не переписывает |
| Без игрока ничего не происходит | NPC живут по распорядку, мир меняется со временем |

## Принципы

0. **Должно быть весело играть.** Каждая механика проверяется вопросом «это делает игру интереснее?».
1. **ИИ описывает мир, а не управляет им.**
2. **Всё работает локально,** а API подключается только по желанию.
3. **Не нужно уметь программировать,** чтобы создать персонажа или мир.
4. **Можно стать кем угодно и делать что угодно.** Учёный, пожарный, врач, детектив, вор или бог — игра не запрещает странные идеи, а превращает их в историю.

Остальные правила проекта (придуманное остаётся навсегда, NPC знает только то, что видел, только открытое ПО, правила нарушаются только явно) по-прежнему действуют. Они записаны в [CLAUDE.md](../CLAUDE.md), [02](02-game-design.md) и [журнале решений](decisions.md).

## Чего в проекте не будет (пока)

- Боевой системы уровня экшн-RPG: бой пошаговый, с кубиками и анимациями, но без управления в реальном времени.
- Платных функций.
