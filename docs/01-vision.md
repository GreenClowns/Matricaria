# 01. Видение

## В одном предложении

Matricaria — пиксельная ролевая песочница, где мир живёт по своим правилам, а персонажи разговаривают с помощью ИИ, не забывая и не переписывая историю мира.

## Для кого

- Любители ролевых игр с ИИ-персонажами (как SillyTavern), которым нужен **мир**, а не просто чат.
- Те, кто хочет создавать своих персонажей и миры **без программирования**.
- Те, кто хочет играть **локально**, без подписок и облака.

## Чем отличается

| Обычный ИИ-чат | Matricaria |
|---|---|
| Только текст | Пиксельный мир, по которому можно ходить, и сцена с портретами |
| ИИ забывает и путает факты | Факты хранятся в базе, ИИ их не переписывает |
| Без игрока ничего не происходит | NPC живут по распорядку, мир меняется со временем |
| Один персонаж — один чат | Много персонажей с отношениями друг к другу |

## Принципы

1. **ИИ описывает мир, а не управляет им.**
2. **Придуманное один раз остаётся навсегда.**
3. **Каждый NPC знает только то, что видел или услышал.**
4. **Всё работает локально,** а API подключается только по желанию.
5. **Только открытое ПО.**
6. **Не нужно уметь программировать,** чтобы создать персонажа или мир.

## Чего в проекте не будет (пока)

- Боевой системы уровня экшн-RPG: бой будет простым, пошаговым или текстовым.
- 3D-графики.
- Онлайн-сервера: мультиплеер, если появится, будет локальным или прямым.
- Платных функций.
