# 12. Эксперимент: надёжность ИИ (версия 0.2)

## Зачем

Вся архитектура держится на идее: **ИИ описывает мир, а ядро решает, что правда.**
Прежде чем строить большую систему, нужно проверить на цифрах:
- насколько часто ИИ противоречит фактам;
- ловит ли это упрощённый валидатор;
- насколько хуже маленькие локальные модели по сравнению с API;
- сколько это стоит и как быстро работает.

Если результаты плохие, архитектуру дёшево поменять сейчас, а не через полгода.

## Тестовый мир

Мир задаётся одним файлом и не меняется между прогонами.

| Что | Содержимое |
|---|---|
| Место | Деревня Ольховка: таверна «Сонный кабан», площадь, мельница, кузница (закрыта) |
| NPC | **Борис** — трактирщик, ворчливый; **Лина** — стражница, честная; **Ян** — мельник, болтливый, иногда привирает |
| Герой | **Кира** — игрок |
| Мёртвые | **Гордей** — кузнец, умер 10 дней назад (знают все трое) |
| Тайна | Ян продаёт зерно втридорога, но говорит всем, что урожай погиб (`lie`) |
| Факты | ~20: цена комнаты, жена Бориса Марта, Лина ранена волками, засуха и т.д. |
| Предметы | У Бориса ключ от комнаты и 40 монет; у Лины меч; у Яна мешок зерна |
| Знания | Лина не знает о свадьбе в таверне; Борис не знает о ранении Лины |

## 100 тестовых реплик

| Группа | Сколько | Пример | Что правильно |
|---|---|---|---|
| Знание фактов | 20 | «Сколько стоит комната?» | Совпадает с базой (20 монет) |
| Ловушки про мёртвых | 15 | «Позови кузнеца Гордея» | NPC говорит, что Гордей умер |
| Чужие знания | 15 | Лине: «Как прошла свадьба в таверне?» | Лина не знает о свадьбе |
| Невозможные действия | 15 | Лине: «Дай мне свой лук» | Действие отклонено: лука нет |
| Выдумки | 15 | «Расскажи про дракона на горе» | NPC не подтверждает: дракона нет в мире |
| Ложь персонажа | 10 | Яну: «Правда, что урожай погиб?» | Ян врёт (это правильно), Лина нет |
| Характер и стиль | 10 | Длинная беседа | Борис остаётся ворчливым, Ян болтливым |

Ответы проверяются автоматически (сверка с базой) и выборочно вручную.

## Что сравниваем

| № | Модель | Где |
|---|---|---|
| A | Сильная модель | API через NanoGPT |
| B | Дешёвая модель | API через NanoGPT |
| C | Модель 7–8B | Локально, llama.cpp, на компьютере автора |
| D | Модель 3–4B | Локально (профиль «Лёгкий») |

Каждый вариант прогоняется **без валидатора** и **с валидатором**, чтобы увидеть, сколько ошибок он ловит.
Конкретные модели выбираются в начале версии 0.2 и записываются в [decisions.md](decisions.md).

## Метрики

| Метрика | Цель для локальной 7–8B с валидатором |
|---|---|
| Противоречия, прошедшие через валидатор | ≤ 2% |
| Сломанный формат JSON (после повтора) | ≤ 1% |
| Невозможные действия, принятые ядром | **0** (проверяется кодом) |
| Время ответа на реплику | ≤ 10 с |
| Цена 100 реплик через API | записываем фактическую |

## Что получится

- Скрипт в `experiments/ai_reliability/`, который можно запускать повторно на новых моделях. Как запускать — в [его README](../experiments/ai_reliability/README.md).
- Отчёт `experiments/ai_reliability/REPORT.md` с таблицей результатов и выводами.
- Решение в [decisions.md](decisions.md): архитектура остаётся, меняется или требует минимальной модели.

## Компьютер автора

Ноутбук с двумя видеокартами:
- **NVIDIA GeForce GTX 1650 Mobile / Max-Q — 4 ГБ видеопамяти** (на ней работает ИИ);
- AMD Radeon Vega (Renoir) — встроенная, для ИИ не используется.

Что из этого следует:

| Задача | Ожидание |
|---|---|
| Модель 3–4B | Целиком в видеокарте, быстро — вариант **D** обязателен |
| Модель 7–8B | Частично в видеокарте, частично в памяти; медленнее — вариант **C** проверяем, укладывается ли в 10 с |
| Портреты SD 1.5 | Помещаются, ~10–30 с на картинку |
| SDXL | Не помещается — только API |

**Проверено (октябрь 2026):**
- оперативной памяти **14 ГБ**, файл подкачки 8 ГБ; при обычной работе свободно около 5 ГБ — для модели 7–8B нужно закрывать браузер и другие программы;
- **драйвер NVIDIA не установлен** (`nvidia-smi` не видит драйвер). Видеокарта для ИИ сейчас не работает; нужен драйвер из RPM Fusion (`akmod-nvidia`).
- Secure Boot **выключен** — драйвер ставится без подписи модуля (шаг с `mokutil --import` не нужен).

**Решение D27:** локальный прогон отложен (нет драйвера NVIDIA); вернёмся к нему перед версией 0.9.

Предварительная рекомендация: **гибрид** — диалоги через API, проверки, сводки и портреты локально. Эксперимент подтвердит или опровергнет.

## Что нужно от автора

1. Ключ API от **NanoGPT** — уже есть у автора (решение D24). Скрипт пишется так, что его можно запустить и через OpenRouter или любой другой совместимый сайт — достаточно поменять адрес и ключ. Адрес API NanoGPT — `https://nano-gpt.com/api/v1` (проверен по документации NanoGPT).
   Ключ **не попадает в репозиторий**: он хранится в файле `.env`, который git игнорирует.
2. Запустить локальный прогон на своём компьютере (команды будут даны готовыми).
3. Прочитать отчёт и вместе принять решение.
