# Эксперимент 0.2: надёжность ИИ

План эксперимента — в [docs/12-ai-experiment.md](../../docs/12-ai-experiment.md).
Здесь — как запускать.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `world.toml` | Тестовый мир: деревня Ольховка, 3 NPC, 21 факт, предметы, кто что знает |
| `cases.toml` | 100 тестовых реплик с ловушками в 7 группах |
| `models.toml` | Настройки моделей A, B, C, D (адрес, имя модели, цены). Ключей тут нет |
| `.env.example` | Образец файла с ключом API |
| `run.py` | Прогон реплик на модели |
| `judge.py` | Оценка ответов: правила и модель-судья |
| `report.py` | Таблицы для отчёта и выборка для ручной проверки |
| `list_models.py` | Поиск точного имени модели на сайте |
| `timing.py` | Куда уходит время: секунды и токены каждого запроса |
| `world.py`, `cases.py`, `llm.py`, `prompting.py`, `validator.py` | Части скрипта |
| `results/` | Результаты прогонов (по файлу на модель) |

## Как это работает

1. `run.py` задаёт NPC реплику. NPC видит **только свои** знания (Лина не знает о свадьбе).
2. Ответ — JSON по формату из [docs/06](../../docs/06-ai-formats.md). Сломанный JSON переспрашивается один раз.
3. Первый ответ сохраняется как **raw** — «без валидатора».
4. Валидатор проверяет его:
   - **действия — кодом** (есть ли предмет, хватает ли денег, жив ли персонаж);
   - **поле facts — кодом**, сверкой с базой;
   - **текст — моделью-проверщиком** (по умолчанию той же моделью, температура 0).
5. Если найдено противоречие, ответ пересоздаётся до 2 раз, затем выдаётся запасной ответ. Итог сохраняется как **final** — «с валидатором».
6. `judge.py` оценивает raw и final: грубые правила по словам и модель-судья, которая знает правильный ответ.
7. `report.py` собирает таблицы.

Валидатор правильных ответов **не знает** — он видит только мир, как в будущей игре. Правильные ответы знает только судья.

## Запуск на Fedora

Нужен Python 3.12 или новее и `uv` (если ещё нет: `sudo dnf install uv`).
Дополнительные пакеты для скрипта не нужны.

### 1. Проверка без интернета и без денег

```bash
cd ~/Matricaria/experiments/ai_reliability
python3 run.py --model fake --limit 10
python3 judge.py results/fake.jsonl --judge fake
python3 report.py results/fake.jsonl
```

Должно получиться: 10 строк вида `[1/10] facts-01: 0.0 с, $0.0016, итог: first`, затем таблица «Сводка».
Поддельная модель нарочно ошибается, поэтому цифры в таблице ничего не значат.

### 2. Ключ API

```bash
cp .env.example .env
nano .env        # впишите ключ NanoGPT вместо «впишите-сюда-ключ», сохраните: Ctrl+O, Enter, Ctrl+X
git status       # файла .env в списке быть НЕ должно
```

### 3. Модели

Откройте `models.toml` и у профилей A и B впишите:
- `model` — точное имя модели на NanoGPT;
- `price_in` / `price_out` — цены в долларах за 1 млн токенов.

Без цен скрипт не сможет следить за пределом трат.

Точное имя модели можно найти так (пример для MiMo):

```bash
python3 list_models.py mimo
```

Для Xiaomi MiMo V2.6 Pro есть два готовых профиля: `mimo` (с размышлениями) и `mimo-fast` (без размышлений, `reasoning_effort = "none"`). Любые дополнительные поля запроса можно задать в профиле строкой `extra = { ... }`.

### 4. Пробный прогон через API

```bash
python3 run.py --model A --limit 5
```

Должно получиться: 5 строк с временем и ценой. Если сайт не понимает строгую схему ответа, скрипт сам перейдёт на формат попроще и напишет об этом.

### 5. Полный прогон

```bash
python3 run.py --model A          # продолжит с места остановки
python3 run.py --model B
python3 judge.py results/A.jsonl results/B.jsonl --judge B
python3 report.py results/A.jsonl results/B.jsonl
```

После 10 реплик скрипт печатает примерную цену на 100.
Предел трат по умолчанию — 2 доллара на файл. Изменить его можно так: `--max-cost 5`.
Если прогон оборвался (нет сети, ошибка сайта), запустите ту же команду ещё раз.

### 6. Ручная проверка

```bash
python3 report.py results/A.jsonl --sample 10 > results/manual-A.md
```

В файле 10 случайных разговоров. У каждого отметьте «верно» или «ошибка».

## Полезные ключи

| Ключ | Что делает |
|---|---|
| `--limit 10` | Только первые 10 реплик |
| `--group dead` | Только одна группа (`facts`, `dead`, `knowledge`, `impossible`, `fabrication`, `lie`, `style`) |
| `--only facts-01,dead-03` | Только эти реплики |
| `--validator none` | Без проверки текста моделью (действия и факты код проверяет всегда) |
| `--validator B` | Проверять текст другой моделью |
| `--fresh` | Стереть прошлые результаты этой модели и начать заново |
