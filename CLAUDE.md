# CLAUDE.md — правила проекта Matricaria

Этот файл читается в начале каждой сессии. Другие чаты не передают сюда свою память, поэтому всё важное должно быть записано в репозитории.

## О проекте

Matricaria — открытая некоммерческая пиксельная ролевая песочница. Мир живёт по правилам, а персонажи разговаривают с помощью ИИ (локально через llama.cpp или через API).
**Версия 0.2 (эксперимент «Надёжность ИИ») завершена, идёт 0.3 «Ядро мира».** Версия 0.1 завершена 26.10.2026. Что делается сейчас и дальше, смотрите в [docs/10-roadmap.md](docs/10-roadmap.md).

## Автор не программист

- Объясняй простым языком, **по-русски**. Если без термина не обойтись, поясни его один раз.
- Команды для проверки давай готовыми блоками для **Fedora Linux**: автор копирует их в терминал. Пиши, что должно получиться в результате.
- Решения, которые меняют игру (механики, внешний вид, порядок этапов), принимает автор. Предлагай вариант с обоснованием, но не решай за него.

## Перед началом работы прочитай

2. [docs/decisions.md](docs/decisions.md) — что уже решено. **Не пересматривай эти решения без просьбы автора.**

## Нерушимые правила архитектуры

0. **Должно быть весело играть.** Предлагая механику, объясняй, чем она делает игру интереснее.
1. **ИИ не меняет мир напрямую.** Он только предлагает действия, их проверяет валидатор, а меняет базу ядро.
2. **Python-ядро — единственный источник правды.** Godot только рисует и передаёт намерения игрока.
3. **Журнал событий только дополняется.** Откат делается через снимки.
4. **Критичное проверяет код, а не ИИ:** предметы, деньги, здоровье, смерть, перемещения.
5. **Симуляция мира работает без ИИ** и детерминирована (seed мира).
6. **Только открытое ПО** и ресурсы с совместимыми лицензиями. Авторов записывай в [CREDITS.md](CREDITS.md).
7. Ядро должно работать и тестироваться **без графики**.
8. **Игрок может нарушать правила явно** (способности, режимы правил, режим рассказчика). Такие изменения тоже идут через ядро и пишутся в журнал с основанием `ability` или `author`.

## Как работать в сессии

- Одна сессия = одна задача из дорожной карты. Работай в отдельной ветке, в конце предложи Pull Request.
- В конце работы:
  - отметь выполненные пункты в [docs/10-roadmap.md](docs/10-roadmap.md);
  - запиши новые решения в [docs/decisions.md](docs/decisions.md) (только дописывай, старые не стирай);
  - добавь запись в [CHANGELOG.md](CHANGELOG.md);
  - дай автору команды для проверки на Fedora.
- Если задача требует решения автора, спроси, а не угадывай.

## Язык и стиль

- Документация, сообщения коммитов, комментарии и docstring'и — **по-русски**.
- Имена в коде (переменные, функции, классы, файлы) — по-английски.
- Текст, который видит игрок (сообщения программы, подсказки, ошибки, консольные команды), — по-английски; другие языки добавим позже в настройках (D40).
- Python 3.12+, стиль PEP 8, окружение через `uv`. К новой логике нужны тесты в `tests/`.
- Модели (`*.gguf`, `*.safetensors`) и сохранения в git не добавляются.
